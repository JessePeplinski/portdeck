# PortDeck 0.1.0-beta.13

- Adds signed in-app update checks powered by Sparkle 2.9.4.
- Checks the PortDeck beta feed once per day without automatically installing updates.
- Shows a quiet **New version available** action in the menu-bar window.
- Adds automatic-update preferences and **Check for Updates…** to Settings.
- Keeps system profiling disabled and verifies both the signed feed and update archive before extraction.

Development builds remain disconnected from the production update feed.
