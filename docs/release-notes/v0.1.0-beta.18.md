# PortDeck 0.1.0-beta.18

- Fixes a provider-tab redraw loop that could cause sustained high CPU usage.
- Prevents Local refreshes from stalling on large helper output and stops cancelled or unresponsive helpers.
- Closes endpoint health checks after receiving status headers and bounds slow responses.
- Limits concurrent discovery inspections to reduce CPU and memory spikes on busy development machines.
- Uses more of the available screen height for the menu panel.
